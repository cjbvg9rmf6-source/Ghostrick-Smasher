# Ghostrick Smasher

A standalone browser game project, separate from Ghostrick Runner.

## Deployment

The playable build is prepared separately. Upload the **contents** of `Ghostrick-Smasher-GitHub-Ready.zip` to the repository root (not the ZIP itself), preserving paths such as `index.html` and `assets/`.

When the files are committed, GitHub Pages can be configured to deploy from `main` / `(root)`.

## Status

Game files are not yet uploaded. Do not treat this repository as a playable release until the complete build and assets are committed and tested.
